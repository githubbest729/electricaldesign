Install on your device

iPhone / iPad (Safari):

  1. Tap the Share button in the Safari toolbar.
  2. Scroll down and choose Add to Home Screen.
  3. Tap Add. The guide opens full-screen and works offline.

Android / desktop (Chrome, Edge): use the Install app button in the header, or the install icon in the address bar.
